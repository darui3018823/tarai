# tarai

竹内関数（たらい回し関数）と、CPU に最大負荷をかける AVX-512 / AVX2 FMA ストレスツール。

## ビルド

```
cargo build --release
```

## tarai

素朴な再帰で `tarai(x, x/2, 0)` を全スレッドで同時に計算する。

```
tarai [x=16] [スレッド数=全部]
```

## burn

FMA 命令をインラインアセンブリで回し続け、CPU の電力と発熱を最大化する。

```
burn [秒数=60] [スレッド数=0(全部)] [avx2|mix|virus]
```

| モード | 内容 |
|---|---|
| (省略) | AVX-512 FMA（非対応なら AVX2） |
| `avx2` | AVX2 FMA |
| `mix` | 半分のスレッドで FMA、残りでメモリ読み書き |
| `virus` | ランダム値 + L1 読み込みの AVX-512 FMA。最も電力を食う |

`virus` モードでの検算値は常に `1522.543` になるので、低電圧化の安定性チェックにも使える。

> 冷却が不十分だと CPU が TjMax（100℃前後）に達してサーマルスロットリングする。長時間の実行は注意。
